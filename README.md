# Text Generation using RNN

This project demonstrates a simple text generation system using a Recurrent Neural Network (RNN).

## Features
- Web scraping from Wikipedia
- Text preprocessing
- Sequence generation
- RNN-based text generation using TensorFlow

## Technologies Used
- Python
- TensorFlow / Keras
- BeautifulSoup
- NumPy

## How to Run
```bash
pip install tensorflow keras beautifulsoup4 requests numpy
python text_generator_rnn.py
